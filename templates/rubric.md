# Rubric lines

Format: `- (wN) criterion`, where N is 1, 3, or 5. Use 5 to 30 lines. State each as a positive, complete, single check.
Weights: 1 = minor polish, 3 = important behavior, 5 = critical behavior.

- (w5) [The command exits with status 0 and prints the total when given a valid input file.]
- (w5) [The function returns an error value naming the missing field when the input lacks a required field.]
- (w3) [The output lists records in ascending order of the date field.]
- (w3) [The endpoint answers an unknown identifier with a not-found status and a body that names the identifier.]
- (w1) [The help text lists every command-line option.]
